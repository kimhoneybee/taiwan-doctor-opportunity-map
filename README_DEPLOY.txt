台灣醫師兼職・合作・合夥＋高齡照護機會地圖

部署方式
1. 下載本專案 ZIP 並解壓縮。
2. 將 index.html 與 opportunities.json 放在同一個網站根目錄。
3. 上傳到 Netlify、Cloudflare Pages、Vercel、GitHub Pages、cPanel/FTP 或其他靜態網站空間。
4. 開啟網站根網址即可。

必要檔案
- index.html
- opportunities.json

注意
- index.html 會從同一目錄讀取 ./opportunities.json。
- 不要只上傳 index.html，否則公開機會資料不會載入。
- 網站使用 Leaflet/OpenStreetMap/ArcGIS 等線上服務，因此瀏覽時需連網。
